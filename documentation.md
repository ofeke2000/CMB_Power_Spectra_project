# Optimal $f_{NL}^{local}$ Estimator Pipeline

## Project Overview
This project implements the unnormalized optimal (minimum-variance) estimator for primordial local non-Gaussianity ($f_{NL}^{local}$) from Cosmic Microwave Background (CMB) data. The pipeline closely follows the methodology outlined in the appendix of Smith et al. (2009), "Optimal limits on $f_{NL}^{local}$ from WMAP 5-year data".

The pipeline performs two major computational tasks:
1.  **Optimal Data Filtering ($C^{-1}$ filter):** It optimally weights the CMB map by applying the inverse signal-plus-noise covariance matrix $(S+N)^{-1}$ using a Conjugate Gradient (CG) solver accelerated by a multigrid preconditioner.
2.  **Estimator Calculation:** It computes the cubic and linear Monte Carlo terms of the KSW (Komatsu-Spergel-Wandelt) position-space estimator using transfer functions generated by CAMB. 

*(Note: This pipeline calculates the unnormalized numerator of the estimator. The final normalization constant $\mathcal{N}$ is not currently computed).*

---

## Workflow Summary
The end-to-end execution is orchestrated by `main.py` and proceeds in the following steps:
1.  **Data Ingestion:** Loads the CMB temperature map and sky mask.
2.  **Noise & Theory Modeling:** Calculates the pixel noise variance from the mask and fetches the fiducial theoretical power spectrum ($C_l$) via CAMB. The monopole and dipole ($l=0, 1$) are marginalized out by setting their theoretical variance to infinity.
3.  **Data Pre-weighting:** Calculates $N^{-1}d$, the data weighted by the inverse noise covariance.
4.  **Conjugate Gradient Inversion:** Solves the system $(S^{-1} + N^{-1})x = N^{-1}d$ to apply the optimal Wiener filter, and then applies $S^{-1}$ to yield the final filtered data $C^{-1}a$.
5.  **Transfer Functions & Kernels:** Extracts CAMB transfer functions $\Delta_l(k)$ and integrates them to generate the radial position-space kernels $\alpha_l(r)$ and $\beta_l(r)$.
6.  **Cubic Term:** Evaluates the KSW cubic estimator by integrating the angular cross-correlation of maps filtered by $\alpha$ and $\beta$ over radial distance $r$.
7.  **Linear Term:** Generates mock signal+noise simulations, passes them through the exact same CG filtering pipeline, and cross-correlates them with the data to compute the Monte Carlo linear correction term.
8.  **Final Output:** Returns $E_{cubic} - E_{linear}$ as the unnormalized $f_{NL}$ score.

## File and Function Reference

### 1. `main.py`
The main entry point and execution script for the pipeline.
* **Workflow Orchestration:** Defines global parameters (`TARGET_NSIDE`, `LMAX`), handles sanity checks on data arrays, logs execution times, and sequentially calls the filtering and estimator modules.
* **`main_fnl_pipeline()`:** The primary function that ties the theory, filtering, and estimator computations together. It calls CAMB, generates the radial grid, and computes both the cubic and linear terms to output the final unnormalized estimator.
* **`benchmark_nside(nside_list)`:** A utility function to benchmark the time taken for spherical harmonic transforms (`alm2map`) at various HEALPix resolutions.

### 2. `filtering.py`
Handles the heavy mathematical lifting for the $C^{-1}$ data filtering. Because $C^{-1}$ cannot be evaluated directly via dense linear algebra, it solves the system using iterative sparse matrix techniques.
* **`cg_solve_Cinv_a(...)`:** The core Conjugate Gradient solver. It iteratively solves $(S+N)^{-1}a$ by defining a custom `LinearOperator` for the $S+N$ matrix vector multiplication.
* **`multigrid_precond(...)`:** A highly optimized multigrid preconditioner that accelerates the CG solver. It evaluates the system on coarser HEALPix grids for low-$l$ modes and uses a simple diagonal preconditioner for high-$l$ modes.
* **`restrict_alm(...)` / `prolongate_alm(...)`:** Vectorized utility functions to extract coarse modes from fine $a_{lm}$ arrays and embed coarse $a_{lm}$s back into fine arrays (used by the multigrid preconditioner).
* **`build_rhs(...)`:** Constructs the right-hand side of the linear system, mapping the noise-weighted pixel data to harmonic space ($N^{-1}d$).
* **`apply_S_N_operator(...)`:** Explicitly applies the $S^{-1} + N^{-1}$ operator. Used in `main.py` to calculate the residual error after the CG solver finishes.

### 3. `estimator.py`
Contains the core physics calculations for the non-Gaussianity estimator using the KSW position-space method.
* **`compute_alpha_beta(...)`:** Integrates the primordial power spectrum $P(k)$, transfer functions $\Delta_l(k)$, and spherical Bessel functions over the wavenumber $k$ to compute the radial weightings $\alpha_l(r)$ and $\beta_l(r)$.
* **`cubic_term(...)`:** Computes the three-point cubic term. It weights the filtered data $C^{-1}a$ by the $\alpha$ and $\beta$ kernels, transforms them back to map space, and performs the angular and radial integration $\int r^2 (A \cdot B^2) d\Omega dr$.
* **`linear_term_MC(...)`:** Computes the linear term via Monte Carlo averaging. It generates mock CMB and noise maps, runs them through the entire CG solver to get $C^{-1}s$, and performs the cross-correlation integral between the simulated maps and the actual data maps to correct for effects like masking and anisotropic noise.

### 4. `theory.py`
Interfaces with the CAMB cosmology code to fetch theoretical predictions based on a fiducial cosmological model.
* **`get_theory_Cl(lmax)`:** Computes the fiducial CMB power spectrum $C_l$. Crucially, it creates a `Cl_safe` array where the variance for $l=0$ (monopole) and $l=1$ (dipole) is set to infinity ($10^{30}$) to cleanly marginalize them out during the $S^{-1}$ filtering step.
* **`get_transfer_functions(...)`:** Runs CAMB to extract the CMB transfer functions $\Delta_l(k)$ and the primordial power spectrum $P_{\Phi}(k)$. It interpolates CAMB's sparse native output into a dense, uniform grid over $l$ and $k$, which is required for the integration steps in `estimator.py`.

### 5. `io_utils.py`
Provides utility functions for file handling, map processing, and logging.
* **`load_maps(data_dir)`:** Reads the CMB map and the sky mask from standard `.fits` files using `healpy`, ensuring NaNs and infinities are safely zeroed out.
* **`downgrade_maps(...)`:** Reduces the resolution (`NSIDE`) of both the CMB map and the mask using `hp.ud_grade`, which is highly useful for testing and debugging without the massive computational overhead of full resolution.
* **`logprint(msg, log_file)`:** A simple logging wrapper that simultaneously prints messages to the console and writes them to the execution log file.

### 6. `test_pipeline.py`
* **`test_lowres_pipeline(...)`:** A lightweight testing script. It runs the $C^{-1}$ Conjugate Gradient solver at an extremely low resolution (`NSIDE=16`) to quickly verify that the data formatting, noise models, and CG preconditioning logic are working and converging before kicking off long, high-resolution production runs.

## Dependencies
This project relies on the following major Python libraries:
* `numpy`: Array manipulation and mathematical operations.
* `scipy`: Interpolation (`interp1d`), numerical integration (`simpson`), spherical Bessel functions (`spherical_jn`), and sparse linear algebra solvers (`scipy.sparse.linalg.cg`, `LinearOperator`).
* `healpy`: HEALPix map handling, spherical harmonic transforms (`map2alm`, `alm2map`), and resolution grading (`ud_grade`).
* `camb`: Code for Anisotropies in the Microwave Background, used to generate fiducial power spectra and transfer functions.
